# 岩心描述与分析系统

一个基于 Web 的智能岩心描述系统，专为石油地质工作者设计，可以实现导入岩心图片、自动识别岩性、构造分析和沉积相类型判断。

## 系统特色

本系统模拟了专业的岩心描述工作流程，通过图像分析技术自动识别岩心特征，为地质工作者提供快速、准确的岩心描述参考。

## 功能特点

- 📸 **智能图片上传**: 支持拖拽上传和点击上传，支持 JPG、PNG、GIF、BMP 格式，最大 10MB
- 🪨 **岩性自动识别**:
  - 识别砂岩、泥岩、灰岩、砾岩、页岩等常见岩性
  - 提供主要岩性和次要岩性分析
  - 显示颜色、粒度、特征等详细信息
  - 给出置信度评分
- 🔍 **构造特征分析**:
  - 识别层理构造（平行层理、交错层理、波状层理）
  - 识别变形构造（断层、褶皱）
  - 识别生物构造和沉积构造
  - 提供构造成因解释
- 🌊 **沉积相智能判断**:
  - 综合岩性和构造特征判断沉积相类型
  - 支持河流相、三角洲相、湖泊相、浊积相、滨岸相等
  - 分析沉积环境和储层潜力
  - 提供可能的替代沉积相
- 🎨 **现代化界面**:
  - 紫色渐变背景，专业美观
  - 卡片式结果展示，信息清晰
  - 响应式设计，支持移动端
  - 流畅的动画效果
- 🔔 **用户体验优化**:
  - 自定义 Toast 通知系统
  - 模态弹窗确认操作
  - 无原生 alert 弹窗
  - 实时加载状态提示

## 技术实现

### 后端技术
- **Node.js 18**: 运行环境
- **Express 4.x**: Web 框架，处理 HTTP 请求
- **Multer**: 文件上传中间件，支持 multipart/form-data
- **Sharp**: 高性能图像处理库，获取图片元数据
- **CORS**: 跨域资源共享支持

### 前端技术
- **原生 JavaScript (ES6+)**: 无框架依赖，轻量高效
- **Fetch API**: 异步 HTTP 请求
- **CSS3**: 渐变、动画、响应式布局
- **HTML5**: 语义化标签、拖拽 API

### 分析算法
当前版本使用模拟算法进行演示：

1. **岩性识别算法** (`analyzeLithology`)
   - 基于岩性数据库匹配
   - 返回主要岩性和次要岩性
   - 包含置信度评分

2. **构造分析算法** (`analyzeStructure`)
   - 识别 7 种常见构造类型
   - 随机选择 1-3 个构造特征
   - 提供成因解释

3. **沉积相判断算法** (`analyzeFacies`)
   - 综合岩性和构造特征
   - 基于关键词匹配评分
   - 返回最佳匹配沉积相及替代方案

**生产环境建议**: 集成深度学习模型（如 TensorFlow.js、ONNX Runtime）进行真实的图像识别和特征提取。

### 容器化部署
- **Docker**: 容器化应用，确保环境一致性
- **Docker Compose**: 单命令启动完整服务
- **Alpine Linux**: 轻量级基础镜像，减小镜像体积
- **Volume 挂载**: 持久化上传文件存储

## 使用说明

### 基本操作流程

1. **上传岩心图片**
   - 方式一：点击上传区域选择图片文件
   - 方式二：直接拖拽图片到上传区域
   - 支持格式：JPG、PNG、GIF、BMP
   - 文件大小：最大 10MB

2. **等待智能分析**
   - 系统显示加载动画
   - 自动进行图像处理和特征提取
   - 分析时间约 1-2 秒

3. **查看分析结果**

   **岩性识别模块**
   - 主要岩性：显示最可能的岩性类型及置信度
   - 次要岩性：显示其他可能的岩性类型
   - 详细信息：颜色、粒度、岩石特征描述

   **构造分析模块**
   - 构造类型：层理构造、变形构造、生物构造等
   - 构造亚类：具体的构造名称（如交错层理、断层等）
   - 成因解释：构造形成的地质意义

   **沉积相判断模块**
   - 主要沉积相：最可能的沉积相类型及置信度
   - 沉积环境：形成该沉积相的地质环境
   - 主要特征：沉积相的典型特征描述
   - 储层潜力：油气储层的潜力评估（高/中/低）
   - 可能的其他沉积相：替代解释方案

4. **新建分析**
   - 点击右上角"新建分析"按钮
   - 确认后清除当前结果
   - 返回上传界面进行新的分析

### 界面功能说明

- **Toast 通知**：操作成功/失败时右上角弹出提示
- **模态弹窗**：重要操作前弹出确认对话框
- **图片预览**：显示上传的岩心图片及文件信息
- **响应式布局**：自动适配不同屏幕尺寸

## 注意事项

### 使用限制
- 图片文件大小限制为 10MB
- 支持的图片格式：JPG、JPEG、PNG、GIF、BMP
- 上传的图片存储在 `uploads` 目录中
- 历史记录最多显示最近 20 条

### 技术说明
- 当前版本使用模拟算法进行演示，实际应用中应集成深度学习模型
- 分析结果基于随机算法生成，用于展示系统功能和界面
- 生产环境建议使用 TensorFlow、PyTorch 等框架训练的岩心识别模型

### 系统要求
- Docker 20.10+ 和 Docker Compose 1.29+（Docker 部署）
- Node.js 18+（本地开发）
- 现代浏览器（Chrome 90+、Firefox 88+、Safari 14+、Edge 90+）

### 端口配置
- 默认端口：3067（与项目编号一致）

## 常见问题

**Q: 如何更换端口号？**

A: 修改 `docker-compose.yml` 中的端口映射：
```yaml
ports:
  - "8080:3067"  # 将 3067 改为你想要的端口
```

**Q: 上传的图片存储在哪里？**

A: 图片存储在 `uploads/` 目录，Docker 通过 volume 挂载持久化存储。

**Q: 如何清空历史记录？**

A: 删除 `uploads/` 目录中的文件即可：
```bash
rm -rf uploads/*
```

**Q: 分析结果不准确？**

A: 当前版本使用模拟算法演示功能。实际应用需要集成训练好的深度学习模型。

**Q: 如何集成真实的 AI 模型？**

A: 在 `server.js` 中替换 `analyzeLithology`、`analyzeStructure`、`analyzeFacies` 函数，调用 TensorFlow.js 或 ONNX Runtime 加载的模型进行推理。
